## Gaps worth addressing

### Realistically closeable with unit tests

1. **`internal/handler/rxnorm.go:89` and `:124` (69.2%)** — likely the search/profile error-mapping paths. Look for uncovered branches in handlers that exist with mocks already wired in `rxnorm_test.go`. **Est: 30 min, +2-3% pkg coverage.**

2. **`internal/middleware/metrics.go:27` (66.7%)** — the metrics middleware wrapping logic. Almost certainly an uncovered error/zero-size branch (e.g., status code 0 handling). **Est: 15 min, easy.**

3. **`internal/handler/cache.go:40` (75.0%)** — `CacheHandler.ClearCache` error path when Redis SCAN fails or prefix arg is invalid. Mockable via miniredis. **Est: 30 min.**

4. **`internal/handler/health.go:136` (75.0%)** — `checkUpstream` returning the resp.Body close error or non-200 status path. **Est: 20 min.**

5. **`internal/handler/spl.go:104` and `:243` (75.0% / 79.2%)** — likely the interaction-check validation paths (drug count 0/1/11+). **Est: 30 min total.**

6. **`internal/service/drugdata.go:140` `AutocompleteDrugs` (57.9%)** — the lowest-coverage function in the codebase, by some margin. This is the stampede-prevention path: `TryLock` failure + fallback to stale index, and the lock-held-by-other-goroutine wait branch. Mocking this requires deliberate concurrency setup (two goroutines, one holding the lock). **Est: 1-2 hours, +5% pkg coverage. Worth doing — it's the autocomplete hot path and the bug surface for L-021/L-022 issues.**

### Gaps that need Redis (integration tests, not unit)

These contribute most of the per-package "missing 20%":

- `internal/apikey/redis_store.go` Create/Get/List/Deactivate/Rotate at 66-89% — the error paths (Redis SET fails, key not found, expired key, etc.) are hard to mock without miniredis at the call site. Most are already covered by `make test-integration`. Untracked under unit coverage.
- `internal/spl/indexer.go` `indexOnce` and `run` (73.2%, 77.8%) — the cache-key-exists short-circuit, the stop-channel race, and the SPL XML parse failure paths. Already partially covered by `indexer_test.go` using miniredis. Diminishing returns from more unit tests.

### Not worth chasing

- `cmd/server/main.go` — 0% by design. Tests would require running the actual server. The make targets exercise it via `make test-e2e`.
- `docs/docs.go init` — generated by swag, intentionally untested.
