# M9.5 — Production Deploy

**Goal:** Establish a production release path with a deploy gate and rollback.

**Status:** IN_PROGRESS  *(repo-side VERIFIED — pending downstream cluster-probe wiring; ready to close)*
**Target Maturity:** GA candidate
**Appetite:** 1 week
**Started:** 2026-06-02

> **Model (pivoted 2026-06-03):** drug-gate **announces** releases; the homelab
> agent ("Joe") **deploys**. A `v*` tag → CI `publish` builds the image → `notify-prod`
> publishes a NATS event → Joe prompts a human in **Discord** → on "yes" Joe runs the
> kubectl deploy, health gate (readiness `/health`), smoke, and rollback. The deploy
> gate is the Discord reply; the health gate + rollback live with Joe. This milestone
> gates the beta → GA promotion (with M10).
